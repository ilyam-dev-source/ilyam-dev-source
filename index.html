01 / Self-directed project

OptBot

B2B ordering

A manufacturer's dealer network, in one ordering workflow: public catalog, negotiated dealer prices, cart review and supplier administration.

TypeScript · Next.js · React · Express · PostgreSQL · Redis

Engineering focus

Application permissions and PostgreSQL row-level security enforce tenant isolation. Server-side quote verification and transactions support the order workflow.

Recording boundary

Catalog, sessions and order transitions run locally. External company lookup, email, KMS and ERP adapters are simulated; the confirmation is not a live ERP connection.

02 / Bachelor's project

Nahodka

Lost-and-found service

Map-based reports and found-item listings help people browse possible matches and contact the partner organization holding an item.

Vue · Django REST Framework · Channels · PostgreSQL · MapLibre

Engineering focus

Persistent messaging with WebSocket delivery, role-specific workspaces and server-side permissions. Listings combine category, description and location.

Recording boundary

The report and messaging flow uses sample accounts with local SQLite and in-memory channels, not the PostgreSQL/Redis deployment setup. A shared category is not proof of an item match.

03 / Self-directed project

CiteDraft

Support-reply drafting

A review workspace for the customer's question, policy sources and proposed reply. Gemini selects relevant facts; an operator edits, checks sources and approves the exact text internally.

TypeScript · Next.js · Gemini · Structured outputs · Evaluation datasets

Engineering focus

Server-validated structured outputs select reviewed statement IDs. Edited text requires another human source check; an audit hash records the exact internally approved draft.

Recording boundary

A real Gemini Flash-Lite response runs in the local application's Cloud Semantic mode. The video shows internal approval, not customer-message delivery. This selected example is not an accuracy benchmark.
