01 / Self-directed project

OptBot

B2B ordering

Dealers browse the public catalog, see their contract prices and review orders before placing them. Supplier managers have a separate workspace to manage dealer accounts and payment terms.

TypeScript · Next.js · React · Express · PostgreSQL · Redis

Engineering focus

PostgreSQL row-level security and application permissions keep each tenant's data separate. The API verifies prices before order creation and uses transactions for order changes.

Demo setup

The catalog, sessions and order workflow run in the local application. Company lookup, email, KMS and ERP calls are simulated. The final ERP confirmation comes from a demo adapter.

02 / Bachelor's project

Nahodka

Lost-and-found service

People publish lost-item reports, browse found items on a map and message the partner organization holding a possible match.

Vue · Django REST Framework · Channels · PostgreSQL · MapLibre

Engineering focus

The database stores messages; WebSockets deliver updates while users are connected. Backend permissions control access to private fields and partner workspaces. Listings include a category, description and location.

About the recording

The video uses sample accounts, SQLite and in-memory channels. The hosted demo uses PostgreSQL and Redis. A category filter helps find candidates; confirming a match still requires checking the item.

03 / Self-directed project

CiteDraft

Support-reply drafting

An operator reviews the customer's question, policy sources and proposed reply side by side. Gemini selects relevant facts, and the operator edits the draft and checks its sources before internal approval.

TypeScript · Next.js · Gemini · Structured outputs · Evaluation datasets

Engineering focus

Gemini selects approved statement IDs. The server validates the selection and builds the draft from reviewed wording. The operator checks any edits against the sources; the audit log records a hash of the exact approved text.

About this demo

The local application's Cloud Semantic mode uses a real Gemini Flash-Lite response. The video shows internal approval, not customer-message delivery. Test results and known failures are covered in the case study; one recorded example cannot measure accuracy.
